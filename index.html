Android app · Kotlin

Simple Android Compass

Pixel phones don't ship with a stock compass, and the free ones I found were full of ads. So I built one: a full-screen compass plus a live home-screen widget that shows true north as the main reading, with magnetic north overlaid so the difference is visible.

  • Turns the phone's fused rotation-vector sensor into a smoothed heading, handling tilt and the jump from 359° to 0°.
  • Calculates magnetic declination offline with Android's World Magnetic Model. The app has no internet permission and no third-party libraries.
  • Updates the widget from a foreground service, only while the screen is on and the heading moves at least 1°, at about 12 updates a second at most.

Web · AWS

This site: three iterations

I have rebuilt my portfolio three times, each time to fix a specific problem. It now costs very little to run and loads quickly worldwide because CloudFront caches it close to each visitor.

  1. Version 1: Node.js, Express, and EJS on Amazon Lightsail (source). A full server for a low-traffic site, which cost money every month and was more than the job needed.
  2. Version 2: Plain HTML and CSS on S3, CloudFront, and Route 53 (source). After a cost and traffic analysis, I removed the server entirely, which cut the cost immediately and made the site faster.
  3. Version 3 (this site): A redesigned front end with no external dependencies, deployed by GitHub Actions that sign in to AWS with short-lived OIDC credentials instead of stored keys (source).
